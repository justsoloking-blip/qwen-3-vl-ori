# 第 1 次课：结构、部署与基线

目标：从未修改的工程运行 Qwen3-VL-32B-Instruct，建立自己的功能与性能基线。

1. 绘制文本、图像、视频输入至输出 token 的结构图，标明视觉编码器、Merger、DeepStack、位置编码和语言模型的职责。
2. 记录 GPU、显存、驱动、拓扑、Python、依赖及模型 revision；执行原始文件校验、环境安装和模型下载。保留安装日志与 `pip check` 输出。
3. 使用原始 TP1 配置部署，完成文字、图片、流式和鉴权请求。原始文件不要提前修改；出现失败时先记录证据。
4. 使用相同输入生成规则、固定输出长度和相同并发，分别测量短文本、长文本、图片与并发请求。预热后至少执行三轮；记录逐请求指标及汇总。
5. 解释 TTFT、输出平均耗时与吞吐的计算口径，区分接口 chunk 与 token。

提交到自己仓库的 `submissions/01_baseline/`：

- `environment.md`：设备、依赖、权重与安装状态。
- `architecture.png`：结构图。
- `commands.md`：实际命令及执行顺序。
- `metrics.csv`：各负载/各轮次的 TTFT、输出耗时和吞吐。
- `conclusion.md`：功能结论、性能基线与尚未解决的问题。

验收：另一位同学能够在相同条件下按照命令重复执行；所有指标能够回溯到请求结果。不能用单次数据代表稳定性能，也不能用模拟请求替代真实模型结果。
